# Credit-Card-Spend-Analysis

I just wrapped up a hands-on case study on Credit Card Transactions Analysis using SQL. This project helped me explore and analyze real-world transaction data to uncover patterns in consumer spending habits across Indian cities.

🔍 Key Insights Derived: 
 1. Top 5 cities with the highest credit card spends and their % contribution
 2. Month-wise highest spends across different card types
 3. Cumulative spends to ₹10L per card type
 4. City with the lowest spend for Gold cards
 5. Highest & lowest expense types per city
 6. Female spending contribution by expense type
 7. Card & expense type with highest MoM growth (Jan 2014)
 8. Weekend spend-to-transaction ratio by city
 9. Fastest city to reach 500 transactions
